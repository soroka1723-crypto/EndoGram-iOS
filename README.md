# EndoGram iOS — этап 1 (полностью офлайн)

Нативное приложение на SwiftUI: клон Telegram, который работает без интернета
и без серверов. При первом запуске аккаунт создаётся автоматически.

## Что внутри

- **Автосоздание аккаунта.** Уникальный ID, имя, `@username`, профиль,
  баланс **1 000 000 тестовых звёзд**, подарки, NFT, Premium и история операций.
  Никаких экранов входа, номеров телефона и SMS.
- **Клон Telegram.** Список чатов с папками, закреплёнными чатами и архивом;
  переписка с пузырями, разделителями дат, закреплёнными сообщениями и
  контекстными действиями; профиль, контакты, поиск, звонки, настройки.
- **Локальная функциональность.** Отправка, редактирование и удаление сообщений,
  создание групп и каналов, покупка подарков и NFT, инвентарь, активация
  тестового Premium, начисление и списание звёзд, история операций.
- **Всё сохраняется на устройстве.** Один JSON-файл в песочнице приложения,
  запись с задержкой и атомарной заменой.
- **Без сети.** В приложении нет ни одного сетевого вызова: ни Telegram API,
  ни собственного сервера.

    └── Screens/                 # экраны

## Архитектура и путь к серверу

Экраны работают только с протоколом `EndoBackend`. Сейчас его реализует
`LocalBackend` (файл на диске). Чтобы подключить собственный сервер EndoGram,
достаточно добавить `RemoteBackend: EndoBackend` и передать его в
`AppEnvironment` — интерфейс и модели останутся прежними.

## Сборка

Xcode на Windows нет, поэтому IPA собирается на macOS-раннере GitHub Actions:

```bash
gh workflow run "Build iOS IPA"
gh run watch
gh run download <run-id> -n EndoGram-ipa
```

Локально (на macOS):

```bash
brew install xcodegen
cd apps/ios
xcodegen generate
xcodebuild -project EndoGram.xcodeproj -scheme EndoGram -sdk iphoneos \
  CODE_SIGNING_ALLOWED=NO -configuration Release build
```

`EndoGram-unsigned.ipa` подписывается любым инструментом (AltStore, SideStore,
Sideloadly, zsign) вашим сертификатом.
